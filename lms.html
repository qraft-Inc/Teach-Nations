Moodle LMS

Access Teach Nations courses and learning pathways via our Moodle instance below.

If the Moodle instance does not display, click the "Open in new tab" button to load it directly.

Integration & LTI notes

  • Recommended: integrate via LTI 1.3 to securely launch courses from the main site and pass user context.
  • For LTI setup you will need: issuer URL, client ID, deployment ID, and a redirect URI on this site (e.g., https://teachnations.org/lti/launch).
  • Alternatively, create direct enroll keys on Moodle and share course links with students.

Need help accessing the LMS? Contact us at info@teachnations.org.
